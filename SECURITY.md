## :warning: Warnings

### :warning: Don't open an issue

- Please do not report vulnerabilities in public issues, pull requests, or discussions.
- Instead, use the private security contact channel defined for this repository.

### :warning: Report privately first

- Send a detailed report including impact, steps to reproduce, and affected versions.
- Include proof-of-concept details privately; avoid posting exploit code publicly.

### :warning: Allow time to respond

- Maintainers will acknowledge reports as quickly as possible and aim to provide a timeline for fixes.
- Coordinate disclosure timelines with the maintainers; avoid public disclosure until a fix is available or agreed.
