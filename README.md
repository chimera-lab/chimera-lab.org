## :telescope: Overview

chimera-lab is a multi-repository organization hosting knowledge bases, research topics, project templates, and scaffolding tools. Repositories are organized by suffix — `.topic` for knowledge and research collections, `.template` for reusable structures, `.scaffold` for bootstrapping tools, `.app` for applications, and `.project` for concrete deliverables.

## :loudspeaker: Introduction

chimera-lab.org is the super-repository and organizational entry point. It aggregates topic submodules and provides shared governance documents, contribution guidelines, and the tooling knowledge base. The [`cmr`](docs/knowledge/cmr.knowledge.md) CLI automates repository management, documentation validation, and template workflows across all repositories.
